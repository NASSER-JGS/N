# ناصر AI — جاهز للرفع على GitHub ثم النشر على Vercel (مجاني)

## الملفات
- `index.html` — واجهة الموقع (بدون أي مفتاح API بداخلها).
- `api/chat.js` — الكود اللي بيتصل بـ Groq نيابة عن الموقع، ومفاتيح API بتتخزن هنا بس بشكل سري (مش داخل الكود).

**لازم تحافظ على نفس ترتيب المجلدات ده بالظبط** (ملف `chat.js` جوه مجلد اسمه `api` في نفس مستوى `index.html`) عشان Vercel يتعرف عليه تلقائياً كـ API.

## خطوات الرفع والنشر

1. اعمل حساب مجاني على github.com (لو مالكش).
2. اعمل Repository جديد (زر New)، وارفعله الملفين دول بنفس الترتيب (اسحب وأفلت الملفات، وخلي مجلد `api` زي ما هو).
3. اعمل حساب مجاني على vercel.com، واختار "Continue with GitHub" (تسجيل دخول بنفس حساب GitHub).
4. من لوحة Vercel: Add New → Project → اختار الـ Repository اللي رفعته → Import.
5. سيبه على الإعدادات الافتراضية، ودوس Deploy.
6. بعد ما يخلص، روح لإعدادات المشروع: Settings → Environment Variables، وضيف:
   - `GROQ_API_KEY_1` = المفتاح الأول بتاعك من Groq
   - `GROQ_API_KEY_2` = المفتاح الثاني (لو عندك)
7. لازم تعمل Redeploy بعد إضافة المتغيرات (من تاب Deployments → آخر Deployment → زر ⋯ → Redeploy) عشان المتغيرات تتفعّل.
8. هيديك Vercel رابط جاهز للموقع (زي `your-project.vercel.app`) — افتحه وجرب ناصر AI.

ملحوظة: مفيش أي تعديل تاني مطلوب في `index.html` — المسار `/api/chat` هيشتغل تلقائي على أي رابط Vercel يديهولك.
